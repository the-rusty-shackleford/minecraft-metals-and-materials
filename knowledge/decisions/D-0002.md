# D-0002 — Steel icons show separate bevelled faces at inventory scale

The steel ingot and nugget are original sixteen-pixel artwork with a cool dark outline,
a narrow upper-left highlight, and separate top/front/end faces. The ingot no longer
reads as a flat clipped rectangle; the nugget keeps a compact irregular silhouette.
The block, item IDs, tags, recipes and creative placement retain their existing behavior.

The small art generator is now strictly typed, returns immutable rasters, validates
pixel-art rows, and reproduces its PNG output byte-for-byte. The source originals remain
in Git history. The new patch version is 1.0.1, held locally. Gun and vehicle consumers
prefer that bundled version while remaining compatible with the existing 1.x API.
