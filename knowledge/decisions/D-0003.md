# D-0003 — Install the shared materials mod separately

Rusty approved removing consumers' bundled copies on 2026-09-18: "Proceed."
Vanilla Wheels and Ranged Weapons Mod keep their required materials dependency,
but no longer embed its jar. Mod Hub installs one explicit version on both sides.
Vehicle add-ons rebuild against the updated Vanilla Wheels so their nested jars
no longer carry older materials copies either.

This supersedes only D-0001's Jar-in-Jar packaging choice. The independent item
registry, common tags, crafting, and Ranged Weapons Mod's old steel alias remain.
An older indirect copy was selected in pack 1.39.1; explicit installation fixed
that in 1.39.2. Removing the copies makes subsequent updates easier to reason about.

Other shared mods retain their existing packaging. Consumers installed outside
Mod Hub must install this required dependency themselves; the loader reports a
missing dependency if they omit it. Publication and deployment remain held.
